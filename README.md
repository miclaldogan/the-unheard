# THE UNHEARD

*An orchestra made of a world you almost forgot to hear.*

An open-source, local-first experience for the Hacktoberfest 2026 Open-Source AI Challenge (Week 1, *Touch Grass*). You teach an amnesiac machine, ECHO-0, to hear by recording the real world; its memory, atlas, artwork and music are built from your recordings.

**Status: architecture phase.** No application code exists yet. Start at [`docs/architecture/README.md`](docs/architecture/README.md) and [`IMPLEMENTATION-BRIEF.md`](docs/architecture/IMPLEMENTATION-BRIEF.md).
