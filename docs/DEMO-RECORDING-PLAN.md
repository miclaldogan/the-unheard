# THE UNHEARD — 60–120 second demonstration plan

Target: 100 seconds, a truthful end-to-end player story for the Touch Grass theme and Best Use of Gemma.
The live challenge details confirm October 11, 2026 11:59 PM PDT (October 12 06:59 UTC / 09:59 Istanbul).
Confirm the [challenge page](https://dev.to/challenges/hf26) before publication. Writing quality is heavily weighted;
explain why local open-weight inference, private acoustic memory and short Field interactions matter.
No competition entry, post or video has been published by this milestone.

## Before recording

- Use a **new disposable profile** for the prologue; keep a separate personally recorded, taught three-source profile ready.
- Record three original sounds with consent and safe surroundings. Do not use ESC-50 evaluation clips in the public video.
- Verify trusted HTTPS on the actual phone, permissions, local persistence and reconnection first. If unavailable, show desktop
  recording and responsive browser Field layout, clearly identified; do not stage it as a validated outdoor phone session.
- Cache CLAP, run it on CPU, start Ollama with `gemma3:4b`; check model status, inference and a render before filming.
- Stop unrelated playback before capture; test output volume with a human listener. Hide tokens, private labels and file paths.
- Preserve authentic pauses. Time cuts are allowed only if disclosed: “processing shortened”; never fabricate instant inference.

## Shot sequence

| Time | Show | Narration / evidence |
| --- | --- | --- |
| 0–12 s | Empty Chamber, ECHO-0’s prologue | “It knows the names of things, but has forgotten their sound.” |
| 12–27 s | A real safe sound outside, then visible Record → Stop → Saved | “The screen is the shortest part. This sound stays on my device until I upload.” Only claim outdoor capture if performed. |
| 27–43 s | Upload, waveform/spectrogram, actual CLAP hypotheses | “Local CLAP hears; these are similarity scores, not certainty percentages.” |
| 43–57 s | Correct the label, committed acknowledgement and memory | “I teach it what this sound means. Retrieval memory changes what it recognizes.” |
| 57–69 s | Measured specimen, Atlas selection and a real relationship | “The acoustic artifact and connections come from this recording.” |
| 69–89 s | Select ≥3 taught sounds, render, play, solo a source, show reacting specimen | “These memories become an original composition.” Use a human-reviewed excerpt; show its actual source. |
| 89–105 s | Grounded Gemma line and expandable facts; persisted ending | “Gemma interprets the evidence. The backend earns the ending; unsupported words fall back safely.” |
| 105–115 s | Repository / closing invitation | “Go outside. Bring back something you almost forgot to hear.” |

Choose Organic **or** Composed as the primary performance; mention the other briefly without cluttering the story.
A single validated Gemma line with its facts is stronger evidence than a long generic chatbot conversation.
If Gemma is pending, show the immediate grounded template and the real later replacement; if it falls back, label that honestly.
